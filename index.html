THE PROBLEM

その作業、
まだ手動でやっていますか？

LINEの返信、SNSの更新、新患フォロー、スタッフへの申し送り——。毎日繰り返される「間接業務」が、院長とスタッフの時間を消耗しています。

AIを正しく導入すれば、これらの9割は自動化できます。

  • 📱
    LINEの返信に追われている 予約確認・来院前の案内・フォローアップ。全部手動では限界があります。
  • 📸
    SNS更新が続かない ネタ切れ、時間不足で投稿が止まる。Instagramは更新しないと埋もれます。
  • 🤖
    AIに院名が出てこない ChatGPTやPerplexityで「京都の整骨院」と検索しても、あなたの院は出てきません。
  • 📊
    数字を見ても経営判断できない GA4・GBP・Search Consoleがバラバラで、何を改善すればいいかわからない。

「AIを使いたい」と思った整骨院の院長が最初に直面する壁は、「業界のことを知らないIT会社に相談しても的外れな提案しか来ない」という問題です。

XAU DESIGNは、柔道整復師として整骨院を経営しながら、同時にPythonエンジニアとしてAIシステムを自ら開発・運用してきた代表が立ち上げたコンサルティングサービスです。

提案するすべてのシステムは自院（せぼねや京都）で先行導入・検証済みです。「机上の理論」ではなく、実際の患者・スタッフ・経営数値と向き合いながら作り上げた仕組みを、そのままあなたの院に届けます。

保険請求の構造、スタッフの心理的ハードル、患者との信頼形成——治療院特有の課題を理解しているからこそ、現場で機能するAI導入ができます。

RESULTS

自院での実証実績

01

次回予約推奨フレームワーク

スタッフが次回予約を患者に勧める際の心理的ハードルを、臨床根拠の論理構造で解消。トークマニュアルとタブレットアプリをセットで整備。

RESULT

スタッフの「売り込み感」による躊躇がなくなり、自信を持って次回予約を推奨できるようになった。

02

LLMO対策 ＋ 集客ダッシュボード

AI検索に院名が登場しない問題を発見。LLM専用ページ新設・ヘッダーメタコード追加・GBPメニュー最適化を実施。GA4・GBP・Search Console統合ダッシュボードも構築。

RESULT

集客指標の視認性が向上し、経営判断のスピードが上がった。LLMO施策は効果測定フェーズへ。

03

LINE × AI新患フォロー自動化

予約後〜来院前・初回来院後・2回目以降の定着・離脱防止の4フェーズを設計。FastAPI + Claude API + Google Sheetsで構築。Renderにデプロイ済み。

RESULT

スタッフの手動LINE送信がゼロに。24時間・個別最適化されたフォローが自動送信される体制が完成。
